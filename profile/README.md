# Blux ⎯ Authentication & Wallet Infrastructure

Blux is an authentication and wallet infrastructure SDK built specifically for Stellar dApps. It gives developers the tools to onboard users, connect wallets, authenticate accounts, sign transactions, manage users, and understand user activity through a single integration.

Instead of building wallet integrations, authentication flows, user management, and analytics separately, Blux brings everything together in one developer-friendly SDK.

## Features

* 👛 **Multi-Wallet Support:** Connect popular Stellar wallets including Freighter, xBull, LOBSTR, Rabet, and Albedo through one unified integration.

* 🔐 **Authentication:** Give users a simple way to authenticate with their Stellar accounts without building the entire authentication layer yourself.

* 🌐 **Social Login:** Let users sign in with familiar providers such as Google and other social accounts, making your dApp easier to access for users who are new to crypto.

* 🔑 **Passkeys:** Support modern passkey authentication for a simpler sign-in experience without passwords.

* 📧 **Email & Phone Authentication:** Give users familiar onboarding options and let them access your application without requiring a wallet from the start.

* ✍️ **Transaction Signing:** Handle wallet connections and transaction signing through the same integration, including Stellar and Soroban applications.

* 🎨 **Customizable UI:** Match Blux to your product with control over themes, fonts, logos, backgrounds, colors, border radius, and other interface elements.

* 👥 **User Management:** Manage authenticated users and access user information through Blux instead of building your own user infrastructure from scratch.

* 📊 **Analytics:** Understand how users interact with your application with insights into authentication activity, user behavior, and login history.

* ⚙️ **Backend API:** Securely access Blux data and user management capabilities from your backend using the Blux API.

* 🌍 **Network Configuration:** Configure the Stellar networks and environments your application uses without rebuilding your integration.

* 🧩 **One Integration:** Bring wallets, authentication, transaction signing, user management, and analytics together instead of maintaining separate systems for each one.

* ⭐ **Built for Stellar:** Blux is designed specifically for Stellar and Soroban developers, with new wallets, authentication methods, and integrations continuously being added.
